📖 1. Advanced Spreadsheet Functions

A spreadsheet is a grid of cells. Each cell has a value, and each value can be used in a formula. Basic formulas like =A1+A2 are useful, but the real power comes from advanced functions.

IF — Make a Decision

The IF function checks a condition and returns one value if true, another if false. 

=IF(A2>50, "Pass", "Fail")

If A2 is greater than 50, the cell shows "Pass"; otherwise, it shows "Fail."

COUNTIF — Count Matching Values

COUNTIF counts how many cells meet a condition.

=COUNTIF(A2:A100, ">50")

This counts how many values in the range A2:A100 are greater than 50.

SUMIF — Add Matching Values

SUMIF adds up values that meet a condition.

=SUMIF(A2:A100, ">50", B2:B100)

This adds the B values where the A value is greater than 50.

VLOOKUP — Find a Value from Another Table

VLOOKUP searches for a value in one column and returns a value from another column.

=VLOOKUP(A2, B:C, 2, FALSE)

This finds A2 in column B and returns the value in column C.

Tip: Always test your formulas with small data first. If the formula works with 5 rows, it will work with 500.

📖 2. Conditional Formatting and Pivot Tables

Conditional Formatting

Conditional formatting changes the appearance of a cell based on its value. For example, you can highlight all scores below 60 in red, or all scores above 90 in green. This makes patterns visible instantly.

How to use it (in Google Sheets):

  1. Select the cells you want to format.
  2. Go to Format → Conditional formatting.
  3. Choose a rule (e.g., "Less than 60").
  4. Choose a color.
  5. Click Done.

Pivot Tables

A pivot table summarizes large data sets. For example, if you have survey responses from 100 students, a pivot table can show you the average score for each grade level in one click.

How to make one:

  1. Select your data.
  2. Go to Data → Pivot table.
  3. Choose "Rows" (e.g., Grade Level) and "Values" (e.g., Average of Score).
  4. The pivot table appears instantly.
Example: A pivot table with rows = Grade Level, values = Average Score, might show:
  • Grade 7 → 72
  • Grade 8 → 78
  • Grade 9 → 81

📖 3. Online Tools for Visualization

Two free online tools make it easy to create professional charts.

Datawrapper (datawrapper.de)

Datawrapper takes a spreadsheet and creates clean, professional charts in three steps:

  1. Upload or paste your data.
  2. Choose a chart type.
  3. Customize (title, colors, labels).

You can then embed the chart in a website or download it as an image.

Flourish (flourish.studio)

Flourish creates animated and interactive charts. You can make a bar chart race, an animated timeline, or a hoverable map. Flourish is especially good for presentations that need to impress.

Tip: Always keep a clean copy of your raw data. If you want to redo a chart, you can upload the same data to a different tool.

🔍 Case Study — How a Pivot Table Saved a Class Two Hours

A Grade 9 class collected a survey of 180 students about lunch preferences. Their spreadsheet had 180 rows and 8 columns.

Their teacher asked them to find:

  • Average satisfaction per grade level.
  • Number of vegetarian-preferring students per grade.
  • Average spend per student.

Instead of calculating each by hand, the class built a pivot table with:

  • Rows: Grade Level
  • Values: Average Satisfaction, Count of Vegetarian Preference, Average Spend

The pivot table summarized all 180 responses in three rows in under 30 seconds.

Then they used conditional formatting to highlight the grade with the highest satisfaction in green, and the one with the lowest in red.

Finally, they uploaded the summarized data to Datawrapper and created a clean bar chart for their class presentation.

Reflect: What would have taken two hours of manual calculation took only minutes. Why is it important to learn these tools now?
