📖 1. How Thai Tones Work

Thai is a tonal language. Every syllable has one of five tones:

  • Mid (สามัญ) — the "flat" tone.
  • Low (เอก) — the tone marked by ่
  • Falling (โท) — the tone marked by ้
  • High (ตรี) — the tone marked by ๊
  • Rising (จัตวา) — the tone marked by ๋

Which tone a syllable takes depends on four things:

  1. Consonant class — high, mid, or low.
  2. Vowel length — short or long.
  3. Final sound — live (sonorant) or dead (stop).
  4. Tone mark — none, ่, ้, ๊, or ๋.
Key idea: The tone mark alone is not enough — you also need to know the consonant class and the syllable structure. That is why this problem is a great fit for a computer program: it has clear rules.

📖 2. Simplified Rules for Mid-Class Consonants

Let's start with the simplest case — mid-class consonants (like ก จ ด ต บ ป อ). The rules for these consonants are shown in the table below.

Tone Mark Live Syllable Dead Syllable (short vowel)
NoneMidLow
่ (mai ek)LowFalling
้ (mai tho)FallingHigh
๊ (mai tri)HighHigh
๋ (mai jattawa)RisingRising

For example, กา (with mid-class ก, no tone mark, live syllable) has a mid tone. But ก่ (with mai ek and live syllable) has a low tone.

Tip: A "live syllable" ends in a long vowel or a sonorant final (m, n, ng, y, w). A "dead syllable" ends in a stop final (p, t, k) or has a short vowel.

📖 3. Writing the Program

Now that we know the rules, let's write them as a Python function. Each rule becomes an if statement. 

def tone(consonant_class, vowel_length, final_sound, tone_mark):
    if consonant_class == "mid":
        if tone_mark == "none":
            return "Mid" if final_sound == "live" else "Low"
        elif tone_mark == "mai_ek":
            return "Low" if final_sound == "live" else "Falling"
        elif tone_mark == "mai_tho":
            return "Falling" if final_sound == "live" else "High"
        elif tone_mark == "mai_tri":
            return "High"
        elif tone_mark == "mai_jattawa":
            return "Rising"
    # Add rules for high and low classes later
    return "Unknown"

# Test cases
print(tone("mid", "long", "live", "none"))       # Mid
print(tone("mid", "short", "dead", "mai_ek"))    # Falling
print(tone("mid", "long", "live", "mai_tho"))    # Falling

Notice that we used nested conditions (an if inside an if). The first decision is the consonant class, and the second decision is the tone mark.

How to read this code: "If the consonant class is mid, then check the tone mark. If there is no mark, the tone depends on whether the syllable is live or dead. If the mark is mai ek, the tone is low or falling..."
