📖 1. The Requirements — What Should the App Do?

Before we build anything, let's define the requirements. Requirements are the answers to the question: "What does this app need to do?"

For our currency converter, the requirements are:

  • Input 1: amount in Thai baht (THB).
  • Input 2: the exchange rate (THB per USD).
  • Action: divide THB by the rate to get USD.
  • Output: the result in USD, formatted with two decimal places.
  • Easy to use: one screen, one button.
Tip: Always ask "What could go wrong?" before writing code. We will handle the case where the exchange rate is zero in the testing section.

📖 2. Writing the Logic in Python

Let's start by writing the logic as a Python function. This is the same function you will later build visually in AppInventor. 

def convert(thb, rate):
    return thb / rate

# Get input from the user
thb = float(input("Amount in THB: "))
rate = float(input("Exchange rate (THB per USD): "))

# Call the function
usd = convert(thb, rate)

# Show the result
print("Amount in USD:", usd)

Let's break it down:

  • Variables: thb, rate, usd.
  • Function: convert(thb, rate) does one job — division.
  • Event: the user runs the program (or taps a button in the app).
  • Response: the program prints the converted amount.
Example run:
Amount in THB: 1000
Exchange rate: 35
Amount in USD: 28.571428571428573

Hmm — that's a lot of decimal places. We'll fix that in the testing step.

📖 3. Improving the Code — Formatting and Edge Cases

Two improvements will make the app much more professional:

1) Format the output to two decimals

In Python, use the format specifier :.2f:

print(f"Amount in USD: {usd:.2f}")

Now the output will look like: Amount in USD: 28.57

2) Handle the division-by-zero problem

If the exchange rate is 0, Python will crash. Let's add a condition:

def convert(thb, rate):
    if rate == 0:
        return None  # Return nothing if rate is zero
    return thb / rate

usd = convert(thb, rate)
if usd is None:
    print("Error: Exchange rate cannot be zero.")
else:
    print(f"Amount in USD: {usd:.2f}")
Tip: Handling edge cases like this is what separates a beginner from a professional. Every real app must think about what could go wrong.

🔍 Case Study — Testing the App with Real Values

A good developer tests every feature before sharing an app. Here are four real test cases for our currency converter.

Test Case Input THB Rate Expected Output
Case 110003528.57 USD
Case 25003514.29 USD
Case 30350.00 USD
Case 4 (edge)10000Error: rate cannot be zero

Why edge cases matter: Case 4 tests the boundary — a rate of zero. This rarely happens, but it can happen (for example, if the user leaves the field empty). Handling it gracefully prevents the app from crashing.
